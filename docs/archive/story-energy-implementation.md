# STORY-ENERGY-003｜故事暮晶戰鬥試玩版

本輪依使用者授權，將故事觸發戰鬥改接獨立的暮晶回合引擎。規則依據與暫定細節見 [實作契約](../story-energy-v1-contract.md)，原始審查見 [規則審查](story-energy-rules-review.md)。沒有把新規則套進自由決鬥引擎，也不改真實存檔。

狀態：新戰鬥試玩版完成，本任務指定的規則、介面、四場真實故事戰鬥及版本驗收通過。既有故事任務仍獨立收尾完整 28 節點演出／存檔／Skin 回歸，不把該任務尚未交回的結果算成本輪通過證據。

## 已交付功能

- 角色固定在場；主角及夥伴有獨立生命、攻擊、護盾和狀態，夥伴由故事關卡提供。
- 暮晶從 0 開始，下一個己方回合起每回合加 1、最多 3；用完逐點恢復。
- 地遁、殘影、武士魂、人劍合一、槍客第四次攻擊判定、遠距免反擊及共振彈分段傷害。
- 選角色、普攻／招式卡、選目標、結束回合、戰況紀錄；勝利繼續故事，失敗重試或返回場景。
- 故事新戰鬥不依賴舊 `S`，不使用舊領域、夜襲或抽牌；退出與回呼各有重複執行保護。
- UI 使用現有本機角色原畫，支援鍵盤、減少動態及圖片失敗時的文字備援。

**需要試玩確認的預設：**全隊共享暮晶；每人普攻與招式各一次且可並用；常駐招式卡；只有技能會反擊；殘影反擊直接扣 HP；低血武士魂可在之後己方回合再次取得；兩種劍客增益可疊加；共振彈 3 費、即時 1 加後續兩次各 1。以上可調部分未假稱為使用者逐項確認。

## 正式故事關卡

所有本輪正式參戰角色維持 10 HP／1 攻，坦克另有初始護盾 2。

| 關卡 | 陣容與目標 |
| --- | --- |
| A2 | 凜對赫爾曼；壓制對手，博士的實驗銃事故仍在戰後演出 |
| S3 | 朔對師父；牽制 6 個完整回合、雙方全員存活，保守 AI；不以擊倒師父通關 |
| E3 | 伊芙對研究區追兵；保留先組裝破鎖、再戰鬥的故事順序 |
| C3 | 凜與伊芙對兩名追兵；朔守前門、格蘭護送磷，沒有任意加入後門戰鬥 |

S3 的 6 回合是配合新 10 HP 規則的試玩配置，取代原故事對戰的 70 HP／50 回合；自由決鬥既有上限不因此改動。

- **UI：5／5 寬度通過。** `tests/story-energy-ui.cjs` 從實際故事 HTML 載入，1440／900／700／390／320px；真實點擊普攻、地遁、結束回合、退出取消、勝利確認、失敗重試，確認回呼一次及本機存檔不變。320px 另含 Tab 焦點圈、Escape 和原畫請求失敗後仍可擊殺並返回。報告 `test-results/story-energy-ui.json` 的 `moduleFixture:false`。
- **人工畫面檢視：**手機與桌面戰場，文字、能量、角色數值與狀態可讀。固定 overlay 使用 viewport 截圖，避免把底下的故事文件拼入全頁截圖；多人手機陣容需垂直捲動。
- **可通關性：4／4 關找到正常 API 路徑。** 沒有補血、改能量或取消敵方行動；下面列明種子與策略。此證據不等於真人難度或所有亂數可通關。
- **真實故事戰鬥流程：4／4 通過。** `tests/story-energy-flow.cjs` 從 A2／S3／E3／C3 的故事節點前進、觸發戰鬥、正常 UI 點擊出招到勝利、繼續戰後故事並收錄一次。僅前置進度與戰鬥用 RNG 為 fixture，未修改血量／能量／終局狀態。A2 另測退出不推進、再進場；C3 在 390px 進行。證據 `test-results/story-energy-flow.json`。
- **資源版本：80 筆引用通過。** 已序列執行 `scripts/version-assets.py` 及 `tests/asset-versions.py`，包括另案 DRAG-UI-005 的共用卡面與新故事戰鬥；之後若故事任務再修改分層素材 JS／CSS，由該任務重新同步。
- **既有故事廣泛回歸：另案進行中。** 故事主責已遷移原 campaign／performance／storage 等測試，與 Skin 回歸並行驗證。其終局 fixture 僅驗回呼；本輪正常出招與通關證據由上述四場真實 UI 流程提供。該主責將另交 `docs/story-energy-integration.md`，本報告不預先宣稱其回歸完成。

### 可重現通關路徑

每場單獨使用 seed 1 的 32 位元 LCG：`x=(Math.imul(x,1664525)+1013904223)>>>0; return x/4294967296`。只經 `legalActions`／`act`／`endTurn` 推進。

| 關卡 | 策略 | 結果 |
| --- | --- | --- |
| A2 | 敵方現有暮晶至少 2 且殘影合法時，先殘影再普攻；其他回合普攻 | 第 10 回合勝，凜 1 HP |
| E3 | 共振彈合法時先施放，再普攻同一敵人 | 第 7 回合勝，伊芙 1 HP；不靠爆擊 |
| C3 | 凜→伊芙，各先合法技能再普攻，集中攻擊 HP＋盾最低的敵人，同值按配置順序 | 第 9 回合勝，凜 5 HP、伊芙 1 HP |
| S3 | 每回合普攻一次，不用人劍合一，再結束回合 | 第 6 完整回合勝，朔 3 HP、師父 4 HP |

A2 同 seed 若「有能就立即開殘影」會敗北；第 4／7 回合留殘影擋地遁能保住行動，顯示施放時機確實有作用。固定所有機率失敗的指定分支中，測過的 A2 兩策略皆敗；這不能推論不存在其他策略，但表示難度與運氣敏感度需要真人試玩。S3 只按結束回合也能通過，目前允許消極過關。
