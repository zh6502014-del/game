## 分組規則

1. **一頁是一段完整交談或事件**，不是一句話。換人說話不分頁；每條原文、署名、原 step ID 皆保留，旁白另外標示，不能把後續說話者串成第一人的台詞。
2. `inspect / search / puzzle / battle / choice / complete` 均為硬邊界，自己成頁；本表沒有跨越其中任何一步。未核定的 action 也獨立。
3. 同一地點的小幅鏡位變化不強制分頁。每組固定使用第一步的安全構圖，不使用後文圖片作首圖或失敗備援、不隨捲動自動換場。說話者以逐段姓名辨識，不讓整頁多人對話共用單一「正在發言」身份。
4. 換日、重大身分／生死揭露、實際轉場及必要意圖保留有意義停頓。尤其 E2 的死訊必須另頁，避免首圖仍讓赫爾曼站在伊芙旁邊；C9 錄音不能變成父親現身。
5. 頁內原文一次完整提供，沒有逐字等待、每句展開鈕或自動跳過。窄螢幕可正常捲動全文；不能為縮短面板刪句、縮字或把同段再切成數個「下一步」。
6. 原始陣列、文字、ID、證據索引與存檔不變。閱讀群是獨立呈現映射，回看只讀；整群涉及的每個 step 都要按原順序記入已讀紀錄，不重新執行已完成的操作。
