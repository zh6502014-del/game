## 討論結論

採用「文明破壞 → 夜域反應 → 環境異變與暮晶 → 文明利用及依賴 → 資源衝突與新破壞」作後續寫作的因果主軸。既有移夜、採掘權與研究封鎖可以自然接上，不必重寫所有起源。戲劇焦點是誰獲得保護、誰承擔代價、誰有權決定；不能因夜域具有防禦意義，就把受害居民的死亡合理化為應得懲罰。

「免疫系統」目前是理解機制的比喻，不等於世界有意識、能辨別善惡或挑選懲罰對象。夜域成因的新方向也不證明每一次移夜都是自然反應：既有人工轉移，是人類對已存在夜域的干預，與根本成因須分層處理。

交接優先順序：先保留暮鐘只能轉移、不能消滅夜域；再區分採掘表、研究樣本與行政命令各自能證明什麼；最後核定死亡材料主張的適用範圍。也不預設每位保護城市的人都知道外移成本；這是避免正邪簡化的敘事建議，不是新增世界定律。

## 建議揭露順序

1. **先讓玩家見到依賴與代價。** 沿既有研究供能、鐘保城、救援盾耗損呈現「可用但有限」；民生依賴可待後續場景核定再補，不增加強制說明課。
2. **再對照利益與受害者。** 用S2／P3行政日期、採掘安排與居民情況揭露誰承擔代價，避免僅憑巧合或殘響定罪。
3. **透過研究與現場逐步釐清材料。** E2的樣本結論、C8的缺漏需後續可追查證據，先處理死亡條件的作者規格；不能用揭密旁白掩蓋目前分歧。
4. **最後才讓角色質疑文明方向。** 當角色已看見保護、採集、軍事／城市依賴與轉嫁，可形成「消滅、控制、利用、共存」的立場爭論；這些是觀點，不自動成立四個正式派系。
5. **世界防禦方向逐漸顯影。** 是否讓玩家確認到何種程度由後續章節決定。保留人的證據限制與反駁空間，不用萬能錄音一次講完宇宙真相。

## 最少待定問題

**真正影響下一次修正文稿的首要問題只有一項：死亡在暮晶形成中是所有晶體的必要條件，還是僅為目前研究樣本的關聯／特殊情況？** 本次新核心未確認，E2與兩份舊稿已寫得更強，須在改它們前定案。

新核心未提死亡，不等於否定舊稿。以下兩種保留方案都可能與新因果共存，均未採定：

- **所有暮晶都需要死亡與長期夜域影響。** 保留博士說法作普遍規則，但需使用者確認；文明依賴的倫理代價更沉重，需交代長期供應與形成時間，不能自動推論所有使用者都知情。
- **夜域可形成暮晶，死亡關聯僅適用特定樣本／形成情境。** 保留博士研究發現的重要性；若採定，需授權調整其未限定的措辭或以後續證據限定範圍，避免無鋪陳地把博士判為錯誤。還須說明特定樣本為何值得權力爭奪，不能臨時編新效能作答案。

其餘不阻擋目前紀錄與討論：暮鐘協會究竟控制哪一段產業／權力鏈、幕城具體定位、各能力來源、玩家何時知道世界成因，等真正編寫相關章節時才逐項核定，不一次要求使用者填滿世界。
