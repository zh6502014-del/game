# STORY-ROUTE-013｜逃離與移動的宮格連路設計

2026-09-25。**討論完成，設計候選尚未實作。** 產品統整劇情、遊戲設計／遊戲樹及故事模式產品的意見。需求：逃離或前往其他地方時，用宮格連接路線的玩法提示行動與空間關係。

## 共同推薦

先用 **T1-step-03「整理已勘查的撤離簡圖」** 做一個小型試點：玩家在固定的5×5簡圖上標出「街口 → 已勘查通道 → 高地接應處」。路段與地形位置固定，以點按或拖曳相鄰格連線；支援不同合法路線，毋須追求最短。

這個時點有停下來規劃的理由，角色手上也確實有渡垣的勘查資料。未來試作應調整既有 `evac` 互動，避免拼完原圖後又被要求多做一道題。012仍在改善現有拼圖操作，兩者目前保持獨立。

玩家體驗分三段：

1. **看懂要去哪裡**：紙面標出起點、必經通道與高地接應處，開場一句交代本次核對的目的。未知資訊保留空白，不顯示未來夜域或敵人動向。
2. **連出一條路**：點相鄰格延伸，點已畫的格子退回。斷線、跨格或撞到不可通路段時保留原線並指出原因；可以撤回、重畫、要求提示。沒有倒數、扣血或居民傷亡評分。
3. **確認並在後文用到**：路線經過指定通道並抵達終點，顯示「路線已接通」，由玩家按「確認路線」。此刻只完成紙面核對；暮鐘提前、原集合點失效之後，在T1-step-06短暫重現同一路線，提示居民正依它轉向高地。這段不再要求重解。

T1完成文案候選：「從街口經過勘查通道，已接上高地的備用接應位置；格蘭記住了這條路。」路線成立不等於接應點永久安全。

## 哪些段落適合

| 情境 | 推薦處理 |
| --- | --- |
| 出發前已有地圖、筆記或勘查資料 | 適合短連路操作；先T1，再評估P4-step-12磷依筆記找渡垣。 |
| 逃離時沿已確認的方向移動 | 用既有路線及位置標記作短演出，讓玩家看見「正在靠近目的地」。是否加入簡短操作需依該場節奏另定。 |
| T2/T3母女與盾牌救援 | 維持近身接應的直接場景操作；幾秒緩衝時不切換成俯視棋盤。 |
| S3牽制、E3破鎖與追兵戰、C3撤離戰 | 保留既有戰鬥與因果順序，連路不能繞過勝負條件。 |
| P4父女分離、C7接應／追查抉擇 | 保留情緒與選擇意義；不以畫線長短代替角色決定，或揭露父親的未知去向。 |
| C8整理觀測區資料 | 維持資料比對，不能讓玩家誤以為已實際抵達。 |

不把每次過場移動都變成一題。實際敘事依據與精確step列表見[劇情適配](STORY-ROUTE-013-story-fit.md)。

## 操作與視覺方向

- 古金細線、墨綠底與既有紙面材質。格線淡化，起終點與接應地標清楚；連線像勘查筆跡，避免用科幻管線或電路外觀。
- 先用向量／CSS畫格子、路線及標記，沿用本機圖示；本輪新增圖片為0，也不預設每格生成美術。
- 手機以點按為主要方式，拖曳為捷徑；每格至少44px。鍵盤可移焦點、連線與撤回；狀態同時用文字、線形與標記辨識。
- 終點未經指定通道時提示「還沒核對指定通道」，保持路線可修改；起始就公開這項要求，不將其他路線描述成必然死亡。
- 關閉不推進故事；暫態草稿是否於同節點保留，由正式接線工單定清。確認只回呼一次，過期session失效；正式收錄仍由原本程序保存。
