# DRAG-UI-005｜拖曳卡面一致性修復

## 原因與結果

拖曳時會將手牌 DOM 複製到 `body`，以免被手牌容器裁切。原先美術樣式依賴 `.duel-hand`／`.duel-screen` 祖先，複本離開後失去 PNG 框、墨綠材質和卡名樣式；兩份舊拖曳規則還將插畫改成70～72%高度與85%寬度，並加上英文 DROP 標記。因此相同原畫在拖曳時看起來像另一套卡片。

新增共用 `card-surface.css`，手牌與拖曳預覽使用同一套卡身、插畫窗、卡名及角標樣式；PNG框也直接共用原宣告。拖曳只改位置、懸浮陰影和目標提示，不另排卡面。基本卡保留完整構圖的 `contain`，職業／特殊卡及解鎖外觀維持各自原畫。

另外修正兩個拖曳呈現問題：尺寸改取未旋轉的布局寬高，避免將旋轉後外接矩形當成牌身而變形；取消自我增益卡拖曳時，正確清除目前 HUD 的目標提示。規則判定、AI、RNG、傷害與出牌呼叫沒有變更。

## 修改檔案

- `card-surface.css`：共用卡面及拖曳懸浮狀態；只匹配舊決鬥手牌與 `.nd-drag-ghost`，不影響新故事暮晶UI。
- `game.js` 的拖曳區段：布局尺寸、相對抓取點、非焦點裝飾複本，以及現行HUD的清理selector。
- `character-art.css`、`unified-art.css`：移除兩份舊拖曳插畫比例。
- `styles.css`：移除拖曳預覽的 DROP 偽元素。
- `png-frames.css`：既有卡框宣告包含拖曳預覽。
- `index.html`、`Nightfall-Duel-V12.12.39-Test.html`、`Nightfall-Duel-Story.html`：共用樣式引用；故事入口由同時進行的故事整合任務負責加入。
- `tests/drag-surface.cjs`：比較拿起前後的圖片來源、插畫布局、卡框、文字、角標，並驗證取消與實際出牌。

## 已執行驗證

- 定向測試：1440／900／700／390／320px × 九種卡牌，共45組；拿起、有效目標、無效目標的卡面資料與布局一致，取消後遊戲狀態不變且提示清除。
- 四套解鎖外觀以320px檢查圖片與拖曳一致；失焦取消、減少動態及一次實際拖牌推進回合通過。頁面錯誤為空。[JSON結果](../../test-results/drag-surface.json)。
- `tests/ui-smoke.cjs`：1440／900／700／390px四組通過；實際拖牌至下一回合、卡片詳情、規則、戰況、音效選單、三種注入終局、再戰及返回。沒有水平溢出或未捕捉的程式錯誤。[JSON結果](../../test-results/ui-smoke.json)。
- 依使用者截圖的 `file://` 本機開啟方式，另行確認一次閃躲卡拖曳：新版原畫、本機PNG框與共用插畫布局載入成功。
- `node --check game.js` 通過。人工檢視[桌面拖曳](../../test-results/drag-surface-1440.png)與[手機拖曳](../../test-results/drag-surface-390.png)，卡面未改成舊圓角版。

## 限制與整合依賴

驗證使用獨立 Chrome 與測試狀態，沒有重整使用者頁面或改寫真實存檔。未做實體觸控裝置、其他瀏覽器或完整遊戲樹驗證。UI smoke記錄到既有音檔請求中止（含一次本機硬幣音檔），本輪未變更或宣稱通過音效播放品質。
