# FX-JOBS-006｜四職業攻擊演出

產品驗收完成。需求：劍客以砍擊呈現，刺客及坦克也要有各自的攻擊特效。

## 實際效果

| 職業／招式 | 發動 | 接觸後 |
| --- | --- | --- |
| 劍客 | 象牙金弧形揮刀、來源牌前壓 | 斜向斬痕與少量金屬碎光 |
| 刺客 | 月紫掠影、短雙刃突刺 | 兩道短刃痕；不使用槍彈火花 |
| 坦克 | 來源牌前壓，接觸區28px短距盾擊 | 鋼青壓力環與盾面重擊；盾型不橫飛整個桌面 |
| 槍手 | 槍口火光、直線子彈曳光 | 小型放射彈著；唯一會建立子彈節點的職業 |
| 劍氣出竅 | 更大的金白劍氣弧 | 放大的斬痕 |

普通攻擊讀取實際施放者職業。傷害事件屬於受影響方，效果來源取相反側；夜襲的閃躲轉攻、刺客及坦克反擊使用各自職業動作。沒有職業資訊時使用中性斬擊備援。

命中痕跡及浮字在既有接觸時點出現；閃避先讓位且不生成命中痕跡或火花。護盾完全吸收時回饋落在盾面，生命面板不震動。灼傷仍為局部餘燼。減少動態保留靜態數值及狀態，取消攻擊移動、掃光與粒子。

## 修改檔案與界線

- 特效／音效 agent：`combat-fx.js`、`character-art.css`中的戰鬥效果規則；使用本機CSS及原創SVG路徑，沒有新增外部素材依賴。
- 產品：`game.js` 在正常及終局兩個呈現呼叫傳入 `{player:{job},ai:{job}}` 職業快照。`combatants` 為可選參數，舊呼叫可依待出牌／HUD取得職業；沒有改動傷害、命中、AI、RNG或回合判定。
- `tests/job-attacks.cjs`：職業、事件、時機、狀態保護及實際結算接線驗證。
- `tests/physical-motion.cjs`：既有直線彈道物理檢查明確指定槍手；沒有再要求所有職業都發射子彈。
- 入口HTML僅由版本腳本更新現有JS／CSS摘要。工作板及本文件記錄交付。

發動節奏維持 `80 + index × 540ms`，接觸等待110–210ms；結束等待和取消機制沿用既有流程。沒有更換音效素材或改動新故事暮晶戰鬥引擎。
