# ENERGY-STORY-002｜故事戰鬥暮晶與四職業規則審查

日期：2026-09-23。狀態：審查交付，規則仍待確認；不是實作規格或平衡通過證明。

使用者希望故事模式採輪流行動的簡易卡牌戰鬥；主角固定在場，夥伴依劇情加入，不由卡牌召喚。本次只審查最新職業草案，不把舊自由決鬥的夜襲、領域、護盾卡等效果自動加入新模式。

## 使用者已提出的規則

| 項目 | 原案內容 | 尚需釐清 |
| --- | --- | --- |
| 暮晶 | 起始 0；下一個回合之後每回合增加 1；上限 3，低於 3 才增加 | 每隊／每角色；補給依誰的回合 |
| 基礎數值 | 普通攻擊 1、血量 10 | 敵方是否也一律相同，或關卡另設 |
| 坦克 | 初始護盾 2；地遁傷害 1、暈眩對手 1 回合，消耗 3 | 護盾結算、暈眩對象及命中條件 |
| 刺客 | 殘影傷害 0，狀態下必定閃避攻擊；50% 反擊對方生命 1；閃避後消失，消耗 2 | 直接攻擊／持續傷害；反擊是否穿盾 |
| 劍客 | 武士魂：HP < 3，下回合普攻 +1，攻擊後消失；人劍合一：下回合普攻 +1，消耗 3 | 武士魂觸發頻率、兩增傷疊加、暈眩與閃避後的消耗 |
| 槍客 | 遠距攻擊不被反擊；累計攻擊 3 次，下一次 10% 爆擊 +1，循環至戰鬥結束；共振彈總傷害 3，涉及兩回合的持續效果 | 計數與重置時機、共振彈各段傷害及費用 |

本文暫沿用「暮晶」字樣，不修改既有世界觀中「暮晶」的名稱。

## 數值與節奏審查

### 1. 暮晶是存量補充，不是每回合補滿

若解讀為第一個己方回合不補、第二個起每次己方回合開始補 1，未消耗時依序為 0、1、2、3、3。2 費招式最快第三回合使用，3 費最快第四回合使用。滿 3 即使用 3 費招式，施放時序為第 4、7、10 回合；花光後下一次只回到 1。

資源所有權尚未確認。三人各自回 1 與全隊合計回 1，是不同的戰鬥節奏，不能混用。暈眩是否影響補能、夥伴中途登場如何初始化也需明訂。

### 2. 普攻與招式的行動額度，優先於調整費用

若人劍合一取代當回合普攻，單看連續兩回合傷害為 0 + 2 = 2，與兩次普攻 1 + 1 相同，卻需花 3 暮晶。集中傷害可能有情境價值，但目前草案沒有足夠機制支持這個代價。

若普攻與招式可以並用，人劍合一才是額外 +1 傷害。然而同為 3 費，地遁已提供當下 1 傷及控制；人劍合一延遲一回合且可能失去出手機會，值得優先試玩比較。這是條件式效果比較，不是勝率結論。

產品建議：先考慮「每名角色每己方回合普攻最多一次，另可施放最多一次暮晶招式」，暫保留使用者數值。若仍乏人使用，再單獨測試人劍合一的較低費用版本，不同時改傷害、費用與時機。此建議尚未獲確認；招式是否必須抽到手牌亦未定。

### 3. 坦克：初始耐久與控制都有效，但配隊規則很重要

若護盾先於生命吸收一般傷害、只給一次且不自動恢復，坦克初始可承受 12 點此類傷害，相比其他角色 10 點多 20%。若有穿盾傷害，不能把 12 當成所有情況的生命量。

單名坦克用完 3 費後，需要三次 +1 補給才能再暈；不是單人永久控制。只有在「允許三名坦克、每人獨立能量、招式每次都可用、暈眩都命中、沒有控制免疫」的假設下，才可第 4／5／6 回合輪流暈同一目標，7／8／9 再續。這不是已確認的可達配隊。

產品建議：暈眩先限定指定敵方角色的下一次行動回合，不解讀為敵方整隊停一回合；待配隊與能量制度確定，再決定是否需要暈眩保護，避免提前加規則。

### 4. 刺客：必閃與反擊機率是兩件事

殘影的閃避率為 100%，反擊機率才是 50%。面對一次 1 傷攻擊且允許反擊時，可阻止 1 傷、期望反擊生命 0.5；不能把所有遭遇都概括為固定 1.5 點價值，因為可以擋到更大的單次攻擊，也可能被槍客禁止反擊。

產品建議：殘影只閃下一次直接攻擊，並避掉該次攻擊的命中附帶效果；消耗後不保護第二次攻擊。持續傷害不觸發或消耗殘影。槍客遠距仍會被閃，但不觸發反擊。這些是待確認的交互建議，非使用者已明定規則。

### 5. 劍客：低血觸發頻率不能留給實作者猜

HP < 3 代表整數生命的 1 或 2，不含 3。武士魂究竟每場只觸發一次、每次由高血跌入低血觸發，還是維持低血就可重複觸發，會產生很大差異；本次不替使用者選定。

若允許武士魂與人劍合一疊加，下一次普攻是 1 + 1 + 1 = 3。需確認這是否為預期爆發。建議同名增傷不重複堆疊；成功宣告並執行普攻後消耗，即使被殘影閃避亦消耗；僅因暈眩未出手則保留。這個「保留到出手」解讀需要確認，不能與「僅限下一回合，過期消失」混用。

### 6. 槍客：10% 爆擊可能難以被玩家感受到

若只在第 4、8、12……次普通攻擊各做一次獨立 10% 檢定，成功或失敗都重置：

- 完成 8 次普通攻擊，只有 2 次檢定；至少爆擊一次的機率是 1 - 0.9² = 19%，從未爆擊為 81%。
- 這 8 次攻擊期望額外傷害 0.2；完整四次攻擊循環中，每次普攻平均額外傷害 0.025。
- 這不是勝率推算，也沒有包含技能計數、提前結束或其他傷害。

先確認計數是否包含招式、被閃的攻擊、反擊與持續傷害，以及失敗是否重置。若要保留原案，至少清楚顯示累計與第四發判定；是否提高機率應待試玩，不在本次逕改。

遠距免反擊的價值取決於反擊制度：若所有近戰都會互相造成攻擊力傷害，這是很強的常駐優勢；若僅明寫反擊的技能會回擊，其價值則取決於敵方配置。兩種模型不可混為一談。

## 必須補明的規則交互

| 情境 | 建議／待決定事項 |
| --- | --- |
| 地遁攻擊有殘影的刺客 | 建議傷害及附帶暈眩一起被閃；殘影消失，再判斷是否可反擊 |
| 槍客攻擊有殘影的刺客 | 建議仍被閃，殘影消失，不反擊；免反擊不等於必中 |
| 暈眩中的角色 | 建議無法普攻或主動施招，仍正常補能並結算持續效果；是否禁止被動反擊待定 |
| 地遁把劍客從 3 HP 打至 2 | 同時涉及武士魂排程與下一回合暈眩；增傷保留或過期需唯一規則 |
| 刺客反擊遇到護盾 | 「反擊生命 1」可解讀為直接扣 HP；需確認是否穿盾，不自動套用舊引擎 |
| 反擊引發反擊 | 建議反擊不再次觸發反擊，避免無限鏈 |
| 共振彈總傷害 3 | 可能為立即 1 + 之後兩次各 1，也可能立即 2 + 之後一次 1；需確認分段及費用 |
| 共振彈持續傷害 | 要定義依誰的回合開始／結束結算、首擊閃避後是否仍附加、再施放刷新或疊加 |
| 角色生命歸零 | 建議每次完整傷害事件後處理倒下，再繼續其他角色行動；主角倒下的勝負條件仍需定義 |
| 暮晶招式取得方式 | 是需抽到的卡，或常駐可用招式，尚未確認；不能只憑能源足夠就判定可用 |

## 後續必要案例（未執行）

以下 12 組是待規則定稿後展開的驗證清單，不是已通過測試：

1. 開局 0、第二至第四己方回合 1／2／3，敵方回合不得重複補能。
2. 滿額停止增加；花 3 後下次為 1；花 2 剩 1 後下次為 2；能量不足禁止施放。
3. 夥伴加入、角色暈眩、重複呈現畫面均不意外增加補給次數。
4. 坦克 2 護盾先吸傷、耗盡後扣血；穿盾與普通傷害分開驗證。
5. 地遁命中／被閃與指定目標暈眩的生效及解除時機。
6. 殘影對先後兩次攻擊只消耗一次，反擊強制成功／失敗各一分支。
7. 殘影對遠距、持續傷害與反擊的分類；不得形成反擊連鎖。
8. 武士魂在 HP 3／2／1 的邊界、觸發頻率、暈眩時保留或過期。
9. 人劍合一與武士魂疊加及消耗；普攻被閃時的狀態解除。
10. 槍客第 3／4／5／8 次攻擊計數及爆擊門檻，成功／失敗／被閃後都按定稿重置。
11. 共振彈各段加總為 3，暈眩期間照常計時，目標倒下後不繼續行動。
12. 在實際允許的配隊與卡牌取得限制下，檢查集中攻擊、連續控制與主角倒下。
