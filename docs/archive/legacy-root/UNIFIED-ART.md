# 全遊戲美術統一與動態決鬥台

## 素材交付

使用內建 image_gen，依既有角色及城堡參考生成 13 張原創 PNG，保留舊版原畫。完整提示詞與生成來源保存在 [assets/generation-log.json](assets/generation-log.json)。

| 類別 | 專案內素材 |
|---|---|
| 共用基本卡 | assets/cards/basic-v2/attack.png、defense.png、dodge.png；原版 assets/cards/ 同名 PNG 保留 |
| 職業技能卡 | assets/cards/swordsman.png、tank.png、assassin.png、gunner.png |
| 特殊卡 | assets/cards/spirit.png、domain.png |
| 透明硬幣 | assets/coins/sun.png、moon.png；兩張均有 alpha 通道 |
| 同構圖背景 | assets/environments/day.png、night.png |

基本卡跨職業共用，職業技能使用角色動作插畫，特殊卡有獨立映射。選角與 HUD 保留人物肖像；既有外觀選擇仍用於肖像，不替換本輪製作的技能動作卡。

## 呈現架構

- card-art.js：9 張卡牌的名稱、來源、分類、圖示及裁切位置。game-art.js 將卡面套用於手牌、放置牌、翻牌正面、詳情；圖片錯誤回退 SVG。
- environment.js：持續背景獨立於每回合重新建立的遊戲 DOM。僅讀取狀態快照，不寫入 S、不使用 RNG。
- 任一方 night 為真即保留夜景，兩方均解除才回白天；硬幣揭曉完成後同步實際狀態，700ms 交叉淡入。回合重新渲染不建立新背景。
- 六種技能環境依玩家／對手順序各 300ms。自由施放的護盾／領域使用各自入口；光影在場地層與背景層，位於卡牌及 HUD 下方。
- 領域低強度刻紋由實際 domainActive 控制。技能結束只移除瞬間光影，不重設日夜；新局、離開、尺寸改變及可見性變更清理瞬間演出。
- 減少動態保留日夜及狀態資訊，省略掃光／霧流；背景載入失敗使用本機底色與既有頁面背景，不卡住出牌。
- unified-art.css：全卡種共用插畫窗、卡名列、類別角標、金屬卡框。硬幣採雙面材質、薄側緣、獨立影子與連續旋轉；文字仍是可讀 DOM。

正文、輔助文字與操作區統一為至少 14px、12px、44px。長敘述靠左，名稱置中，數值用等寬數字。生命徽章參與文件流，避免文字放大被裁切；密集手牌的絕對定位插畫固定在各自卡框內。桌面手機均保留左右玩法。

## 驗收記錄

Chrome 自動化結果及截圖放在 test-results/：

- unified-art.cjs：1440／900／700／390／320px，9 張卡牌各顯示於四處的素材映射，1／4／7 張手牌與插畫邊界，輪播置中；日夜四種雙方組合、跨回合持續、領域開關、雙面硬幣方向、六種技能及順序、減少動態、再戰、返回、圖片失敗備援。另透過 resolveRound 實際驗證刺客進入及解除夜襲。
- gallery-layout.cjs：展示頁 1440／390／320px 的卡片邊界與水平溢出檢查。
- text-zoom.cjs：1440px 下將直接文字元素放大 200%，檢查選角、戰鬥、詳情、音效、規則、結算；保留截圖供視覺複查。
- ui-smoke.cjs：四尺寸選角、拖曳並進入下一回合、選單、三種結算、再戰及返回。
- art-effects.cjs：四職業與狀態、六種局部特效、減少動態及取消、三種確定性攻防案例、翻牌正面、紀錄安全與素材備援。
- physical-motion.cjs／flip-readback.cjs：接觸時序、雙向攻擊、重力、材料回應、正面實際命中測試。

瀏覽器整頁長截圖會使橫向捲動容器的合成圖層出現偏移；選角改用可見範圍截圖並配合實際元素座標驗證。這不是用放寬座標條件通過測試。

## 限制

手機是 Chrome 模擬尺寸，尚未做實機效能驗證；200% 是桌面文字放大檢查。既有外部音效在畫面切換時可能出現 ERR_ABORTED，未宣稱全遊戲離線音效完整。此次不等於完整遊戲樹窮舉，AI／機率／傷害／回合規則未因美術需求變更。
