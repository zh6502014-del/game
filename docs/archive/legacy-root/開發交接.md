# 12. 每個 Selector 的處理方式

不要看到：

```css
.foo {
  ...
}

.foo {
  ...
}
```

就直接合併。

必須先確認：

1. 是否同一 media scope
2. 是否同一 Cascade layer
3. 中間是否存在其他 selector override
4. property 是否重複
5. property 是否被後面覆蓋
6. 是否有 `!important`
7. specificity 是否相同
8. source order 是否有意義
9. 是否是 Mobile Override
10. 是否是 Final UI Patch

只有能證明 computed style 不變時才能合併。

---

# 13. 合併策略

優先級：

### A. Safe

同 selector
同 scope
不同 property
沒有 cascade dependency

→ 可以合併。

### B. Dead Declaration

前面的 property 後面被同 specificity、同 scope 永久覆蓋。

→ 可以移除前面的 declaration。

### C. Intentional Override

Base：

```css
.foo {
  width: 100px;
}
```

Final Patch：

```css
.foo {
  width: 120px;
}
```

→ 不要合併。

這是 intentional override。

### D. Responsive Override

Base：

```css
.foo {
  width: 120px;
}
```

Mobile：

```css
@media(max-width:700px) {
  .foo {
    width: 90px;
  }
}
```

→ 絕對不要合併。
