# 典藏決鬥台精修

2026-09-23 完成。延續既有角色與城堡原畫，以本機 SVG、CSS 材質及版面細節統一戰鬥畫面；沒有新增圖片服務或改動遊戲判定。

## 視覺變更

- 頭像改為切角典藏卡框，96×116px／80×100px／56×70px，帶斜角金屬、細刻線、四角裝飾及嵌入式職業紋章；八套既有外觀各自裁切。
- 資訊卡改為墨綠琺瑯銘牌，角花採固定尺寸九宮切片，避免窄螢幕拉長變形。生命、護盾、狀態保持獨立排列。
- 手機名稱保留完整文字，文字放大時整組移至頭像下方，不拆成直排。
- 桌面使用平面鑲邊、低對比皮革紋、原創羅盤刻紋；日夜保留不同底色，不蓋住技能環境演出。
- 出牌槽使用內凹陰影與細邊，回合標記使用金屬琺瑯章，ROUND 與回合數明確分成兩行。
- 操作列使用同套金屬按鈕，保留 44px 操作區和鍵盤焦點輪廓。

實作入口為 `arena-finish.css`、`hud.css`；原創裝飾為 `assets/icons/collector-portrait-frame.svg`、`collector-corners.svg`、`table-inlay.svg`。沒有改動翻牌正反面的不透明度、裁切容器、傷害計算或 AI。

## 驗證

- `hud-polish.cjs`：五種寬度 × 兩種文字大小 × 七種生命值，共 70 組；小數護盾、完整狀態、左右等高、數字欄不跳動，全部通過。
- 八套外觀 × 五種寬度共 40 組，以及圖片失敗備援、首頁與故事入口通過；八套裁切另經人工檢視。
- `unified-art.cjs`：卡面映射、日夜維持、雙方夜襲、技能演出、減少動態與場景清理通過。
- `flip-material.cjs`：1440／390px 各九個翻牌進度，包含側面 90°；正反面不透明與完整覆蓋牌身通過。
- `ui-smoke.cjs`：1440／900／700／390px 的點牌、拖牌、翻牌、選單、三種結算、再戰與返回通過。
- `text-zoom.cjs`：桌面六種主要畫面文字放大 200% 通過。
- `asset-versions.py`：58 個 CSS／JS 引用的內容版本一致。
- 另開 Codex 內建瀏覽器分頁檢視實際畫面，確認頭像裁切正常、資源帶版本且無水平溢出；未重整使用者原本的對局。

響應式驗證使用桌面瀏覽器模擬，未使用實體手機。舊有遠端音效在頁面切換時仍可能回報 ERR_ABORTED，不影響本次通過的遊戲流程。
