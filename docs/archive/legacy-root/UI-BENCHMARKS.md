# 夜幕決鬥：介面精修與易用性

## 視覺參考

- [GWENT 官方媒體](https://www.playgwent.com/en/media)：參考角色卡面主導的層級、暗色戰場與金屬卡框。保留夜幕決鬥左右對戰的規則與配置。
- [MTG Arena 官方行動介面介紹](https://magic.wizards.com/en/news/mtg-arena/mtg-arena-state-game-january-2021-01-21)：參考行動裝置的操作清晰度與可操作狀態區分。

以上是本專案的設計取捨；沒有使用其他遊戲的角色或介面素材。

## 本次實作

- 英雄選角採完整原畫、原創角花、職業角標及漸層資訊區，四職業維持相同構圖語言。
- 戰鬥 HUD 使用拱形肖像、金屬生命徽章、護盾格與可換行狀態；玩家與對手保持對稱。
- 原創 SVG 戰場刻紋降低對比，主畫面使用既有生成城堡背景與角色美術。
- 放大手牌，4 張以上改為受戰區寬度限制的重疊排列；選角首尾卡修正置中。
- 點擊卡牌可閱讀效果並選擇「打出此牌」或「施放護盾」，沿用原有 playCard 判定。保留拖牌。
- 詳情支援 Escape 返回、Tab 焦點循環與返回後恢復焦點；顯示可見鍵盤焦點。
- 放大手機技能、AI 戰術與狀態文字，縮短戰場空白，保留左右出牌區。
- 未變更 AI、傷害、回合規則或對外 API。

## 驗證

Chrome 自動化與截圖檢查：1440、900、700、390px。結果位於 test-results。

- ui-smoke.cjs：選角、拖牌並進入下一回合、戰況、規則、音效、卡牌詳情、勝敗平手、再戰／返回；檢查水平溢出及未捕捉例外。
- prestige-layout.cjs：四職業輪播置中、4／7 張手牌邊界、Escape 返回、點牌出牌並進入下一回合。
- art-effects.cjs：四職業肖像與狀態、六種特效、減少動態、動畫取消、紀錄文字安全與圖片備援，三個固定戰鬥案例。
- flip-readback.cjs：180 度翻牌完成後，正面確實參與繪製與命中測試。

這些測試涵蓋本輪介面與互動，不代表完整遊戲樹窮舉。手機為瀏覽器模擬尺寸，尚未實機驗證。既有外部音效請求在畫面切換時仍有 ERR_ABORTED 紀錄，未宣稱所有音效均可離線播放。
