# 頭像與戰鬥資訊面板精修

完成日期：2026-09-23。沿用角色原畫，不改 AI、傷害、機率與回合判定。

## 實作

- `hud.css` 集中管理頭像、名稱、生命、護盾與狀態；移除五份既有樣式中對這些元件的重複覆寫。主遊戲、故事頁與首頁均載入此樣式。
- 四職業與四套 origin 外觀各自設定 HUD 裁切，僅影響頭像；選角、手牌、翻牌與詳情仍沿用原來的素材邏輯。八套頭像已人工檢視額頭、眼睛與下巴。
- 使用單一拱形斜角金屬框，搭配原創 `assets/icons/portrait-engraving.svg` 刻線與職業角標。角色色彩限於局部紋章；玩家與對手面板共用墨綠底材與尺寸。
- 頭像、身分、資源、狀態使用獨立 grid 區域；桌面鏡像排列，手機兩邊都採頭像／名稱在上、資源在下。左右面板等高，狀態增加時自然增高。
- HP 使用等寬数字和固定預留空間，小數變更不移動數值欄；裝飾裁切只放在偽元素背景。標籤與數值在空間不足時自然換行，文字不縮小、不裁切。
- `hudNumber` 僅格式化顯示為最多兩位小數並去掉尾零，不回寫戰鬥狀態。
- 外觀圖片失敗時切回基礎原畫並同步切回裁切設定；基礎原畫也失敗時顯示職業紋章。

## 2026-09-23 快取混用修復

使用者回報圖片超出頭像框。直接檢查使用者正在開啟的 Codex 內建瀏覽器後，確認頁面同時載入新版 `hud.css` 與快取中的舊版 `game.js`、`game-art.js`：DOM 缺少 `.battle-hud`、`.duel-identity` 和 `.portrait-window`，頭像圖片以原始 1024×1536 尺寸顯示。先前 Chrome 的乾淨載入測試未涵蓋此更新路徑。

修正所有 HTML 入口的本機 CSS／JS 引用，加入內容 SHA-256 版本；新增 `scripts/version-assets.py`，每次修改 CSS／JS 後執行以同步版本，再執行 `python3 tests/asset-versions.py` 檢查引用。並為舊版直接子圖片結構加上明確尺寸限制，避免缺少裁切容器時原圖覆蓋畫面。

已在使用者原本的瀏覽器分頁重新載入，選擇槍手對坦克並開始新局。實際畫面已確認兩側頭像正常；DOM 檢查確認全部 CSS／JS 使用版本 URL、兩個頭像內層均為 `overflow:hidden` 且位於框內、無水平溢出。重新載入會重建當局，本次回到相同職業組合的新局。
