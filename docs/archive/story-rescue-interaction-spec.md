## T2：接應與護送

場景顯示格蘭、母女、狹窄通道和出口隊員。開始先看清接應位置；選取人物後，可選場景中的合法目的地或接應者，亦支援點選與鍵盤。人物不作形狀配對零件。

1. 玩家查看通道及出口接應者，確認有人能接手女孩。
2. 選擇女孩，再選出口隊員，演出格蘭協助交接；女孩抵達後留下可見的安全狀態。
3. 選擇母親並選通道接應位置，格蘭陪同前進；若孩子尚未交接，提示原因並保留場景，不強行成功。
4. 完成交接及護送後，才播放母親跌倒，進入 T3。沒有獎勵越過救援或把人留在原處。

本節重點是人員位置與交接順序，不增強迫倒數、隨機受傷或永久失敗。

## T3：短暫掩護與接力

場景預先標出可插盾的位置、母親與出口隊員，交代盾只能爭取片刻。採離散操作步驟呈現緊迫，不要求玩家拼手速。

1. 選盾並指定通道內經確認的掩護位置，演出盾啟動；未部署前不能執行下一段護送。
2. 選母親與出口隊員建立接應；以畫面與文字同時標示方向，聲音只輔助。確認母親抓住隊員後才標為交接完成。
3. 玩家選取格蘭，再選伸手接應的隊員，放盾撤離；若母親尚未交接，先提示需要完成接力。
4. 演出隊員拉出格蘭、盾崩裂與既有結尾。盾不被修復，夜域不被擊敗。

每步要有場景狀態變化與操作結果，禁止以不可見計時器替代救援判定。台詞仍承接情緒，不作操作本身。
