## 使用者世界觀參考摘要

以下為忠實摘要而非逐字原稿；未列細節仍以使用者原文為準。

文明過度開發／戰爭／破壞 → 世界產生夜域反噬或防禦反應 → 環境異變 → 長期夜域影響形成暮晶 → 採集、交易、研究、加工 → 能源、設備、武器與城市技術 → 政權及文明更加依賴暮晶 → 爭奪資源與夜域控制權 → 新的干預及破壞 → 夜域問題加劇。

核心命題：**人類利用災難本身對抗災難，最終卻因此無法離開災難。** 夜域既威脅生存，也提供文明對抗它的資源；人類與夜域不是單純正邪對抗。世界的「免疫系統」是理解因果的比喻，不自動等於世界有思想、意圖或審判個人的能力。

| 設定 | 後續創作採用方式 |
| --- | --- |

## 明確保留的空白

- 幕城「可能」是運用暮晶抵抗夜域的城市；具體城史、行政架構、誰控制它未定。舊終章的調度中心配置仍是提案。
- 人體變化、暮晶人體實驗及能力來源仍是概念；不得把四職業一律寫成暮晶改造人。技術、訓練、裝備與環境都可能是來源，尚無全職業結論。
- 消滅、控制、利用、共存只是思想方向，未成立四個正式派系，也不等於每人只能屬於其中一種。
- 暮鐘協會與暮晶、夜域、城市政府及政治科技的完整關係未定；未來至少需有一條直接因果，不能先宣告其控制一切。
- 不自行補夜域形成門檻、恢復年限、資源再生率、死亡必要性、世界人格或完整歷史。
- 2026-09-28 已統一用字為「暮晶」；「幕城」「暮鐘」「暮鐘協會」維持原寫法，未更動。

## 創作與揭露約束

先世界規則，再歷史事件、文明發展、勢力形成、利益、角色立場、衝突及故事。科技要有代價，重要設定要有因果；任何具體代價仍須與已確認內容分開，不能以「合理」為由補完。

作者知道的規則、角色根據證據知道的事、玩家此時能看到的線索分開記錄。現有主角觀察到資源交易或研究事故，不足以立刻證明全球文明造成夜域。核心因果可作後續敘事指南，是否以及如何在正文揭露，仍需另定具體工單。
