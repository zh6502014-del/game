# docs/design 分類

為符合專案項目數限制，設計工單及設定圖集已無損封存至桌面存放區的 091 批次與早期歷史封存，原路徑保存在封存內，同名檔優先查 091 新版。現用角色美術規範與測試依賴保留原位；封存未變更任何工單狀態。查看工單或角色圖鑑前，按 [存放區說明](../../storage/README.md#設計工單與歷次驗收資料) 還原至專案外，再以原相對路徑開啟。

| 資料夾 | 內容 |
| --- | --- |
| `story/` | 劇情、台詞、章節重寫、文字對齊（含 `story-dialogue-*.xlsx`） |
| `art/` | 美術工單：立繪、插圖、場景、素材封存、槍械統一、迷宮與道具 |
| `fx-audio/` | 特效與音效：音訊混音、預設音量、決鬥音效、戰鬥特效、盾牌節奏、研究室震動 |
| `ui/` | 介面：手機版、按鈕、離場、卡牌放置、支線介面、戰鬥介面 |
| `project/` | 專案維護：整理、上傳 GitHub |

檔名格式：`<主題>-<工單編號>.md`，審查報告為 `<主題>-<工單編號>-review.md`。
