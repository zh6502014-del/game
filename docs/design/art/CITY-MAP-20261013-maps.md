# 城市地圖與地區製作規格

## 世界布局圖

本圖展示八城與三地區的統一美術布局提案。北上、東右是圖面閱讀方向；維斯珀蘭位於大陸西側、諾德馬克在北、艾許莫爾在東為C。八城在紙面上的精確點位皆D，不宣稱原故事已確定公里或行程天數。

| 編號 | 城市 | 图面配置D | 必須保持的C身分 |
| --- | --- | --- | --- |
| 01 | 暮城 | 中西部、有城牆的主要城市 | 王都、中央唯一暮鐘 |
| 02 | 莫爾威爾 | 中東部、以歷史廢墟符號標記 | 十年前遭移夜；現代重建未知 |
| 03 | 迪普霍姆 | 東南山麓 | 地表礦業小城與附近礦坑；非全城地底 |
| 04 | 格雷海文 | 西南內河 | 河港、暮晶轉運 |
| 05 | 弗羅斯福德 | 北方渡口 | 通往諾德馬克，不限定冰封 |
| 06 | 蘭維爾 | 西北丘陵山谷 | 前傳撤離到附近高地 |
| 07 | 阿恩費爾德 | 中南平原 | 暮城士兵團駐地 |
| 08 | 索爾布魯克 | 南方農地 | 農業供應暮城糧食 |

世界圖不是同一時刻的情報地圖：莫爾威爾用歷史廢墟狀態辨識，其他城市用功能設計；不能推論八城同時發生事件。河流、分支、橋樑與道路D以連續地形呈現；道路只示意交通，不代表唯一可通行線。海、山、河無新增專名。無國界色塊、移夜固定光束或永久安全圓罩。

## 暮城市區圖

以現行入口街道、鐘樓及前次場景板為材質基準，外觀石木結構、墨綠遮棚、旧金金屬。中央鐘樓只一座；城南廢倉依G1正文。其餘各地標的相對位置是D，供美術維持連續取景。

| 編號 | 地點 | 位置及使用規格 |
| --- | --- | --- |
| 01 | 暮鐘／鐘樓廣場 | 城中央C；地下操控室與維修區按既有世界板，不增第二座鐘 |
| 02 | 曜火研究所 | 東北片區D；高窗與研究室沿用已定稿內景 |
| 03 | 行政文件庫 | 東南內區D；外區→資料廳→內區的劇情順序保持 |
| 04 | 尺烏據點 | 西側院落D；地點不代表公開掛滿組織標誌 |
| 05 | 城門與入口街道 | 西南D；厚石拱與素墨綠棚沿用既有視覺 |
| 06 | 城南廢棄倉庫 | 南側C；具体街巷和棟距D；不得當成另一具名城市 |
| 07 | 民居／工坊 | 東侧街廓D；為城市生活尺度，無新增具名人物事件 |
| 08 | 城外舊路 | 城外C、出城方向與轉折D；不把此路等同蘭維爾撤離高地 |

地下剖面限鐘樓局部，沒有連到其他地標的秘密隧道。城門、城牆與建築用圖形区分；不將大門尖塔畫作第二座暮鐘。市區圖採鐘樓毀壞前，H2後鐘樓地塊狀態另按故事，不能把整城強制清空。

## 地區氣氛：諾德馬克／艾許莫爾

- 諾德馬克C為北方高地。D：層疊風化岩、低矮石楠／草坡、冷灰天空與古舊土石路。冷調不代表永冬、雪國或新族群。
- 艾許莫爾C為東方荒原。D：乾燥灰褐碎岩、侵蝕台地、稀疏灌叢及開闊低彩度地平線。不新增火山、沙漠王國、具名廢城。
- 地形剖面僅說明造型節奏，無工程尺度。北地偏冷灰石、荒原偏乾燥褐灰，兩者不以更換整套科技／建築文明來區分。

## 路線與圖例規格

| 關係 | 已確認內容 | 圖面使用限制 |
| --- | --- | --- |
| 暮城→迪普霍姆→暮城 | 現代調查出城、深入礦坑、帶納爾瓦回城 | 可標行程順序，不以線長推日數或插入必經他城 |
| 索爾布魯克→暮城 | 糧食供應 | 功能物流，不新增事件或壟斷制度 |
| 格雷海文→各城 | 暮晶轉運 | 不指定每一批貨的實際去向與船陸比例 |
| 弗羅斯福德→諾德馬克 | 北方通道 | 不擴成已確認國界或軍事關卡 |
| 蘭維爾→附近高地 | 前傳撤離 | 高地只暫時未被夜域籠罩，不等同諾德馬克 |
| 暮鐘→莫爾威爾 | 十年前移夜目的地 | 非永久風向，不畫固定地表傳送軌道 |

符號：實體城鎮用城屋剪影；廢墟用破屋剪影；礦坑用山麓坑口；河港用內河碼頭。點線道路為D交通提案。夜域若後續做覆蓋層，應獨立且可變，不能在基礎地圖刻成國界。中文名稱由設定頁及正式文字層提供，生成圖的裝飾標語不是新正史。
