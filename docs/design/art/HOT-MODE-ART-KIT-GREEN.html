熱血模式美術包（墨綠版）

熱血模式不用 CSS 改色，所以素材本身要跟遊戲一樣是墨綠加古金。這份把先前的紅色版 6 張改成墨綠版：熱血感只留在火焰造型與琥珀色的火光，不再用紅色底。每一張都附上現有紅色版當構圖參考，所以是「改色重畫」，不是重新設計。圖由你生成，不由 Claude 代畫。

流程

  1. 依順序生成：A → B1 → B2、B3 → C（附 A）→ D。
  2. 每張依參考圖順序附上，再貼 prompt；標「先生成」的要附你剛生成的成品。
  3. 生成好的檔案放進 Game_claude 的 source-art 資料夾，告訴我檔名；我覆蓋同名素材、重量九宮格切線、轉 WebP 並跑容量檢查。
  4. 先前的「墨綠底紋」兩張（HOT-GREEN-BASE-KIT）不再需要，這份取代它。

A　熱血徽章（墨綠版）

用途
備戰大廳切換鈕上的「熱血」圖示。保留火焰，底色改墨綠。
輸出
1254×1254 以內 透明底 PNG；遊戲載入 256×256 WebP，80KB 以內
檔名
hot-badge（接入後覆蓋：assets/ui/hot-badge.webp）

參考圖（依序附上）

Prompt

Use case: stylized-concept. Single transparent game icon asset, detailed realistic dark-fantasy, deep ink-green and antique-gold palette (the game's own green-and-gold look), with hot-blooded energy carried ONLY by flame motifs and warm amber ember glow, NOT by red enamel. Restrained and heavy, painterly forged-metal look, same style, lighting and colour grade as the existing green-gold frames and cards (NOT cartoon, NOT neon, NO red or crimson fields). Repaint reference1 (an existing RED version) so that every red/crimson area becomes deep ink-green enamel (about the lightness and hue of reference2/reference3) while all gold trim stays antique gold. Keep reference1's composition and geometry exactly; only the colour scheme changes. Flames and embers become amber-gold with a pale-gold core and a few warm orange tips, no red. Round embossed coin-style emblem, SQUARE canvas, filling about 92% of the canvas with an identical thin transparent margin on all sides, centred; field behind the flame is deep ink-green enamel, rim and ornaments antique gold. It must read as the same set as reference2 and reference3. Genuine transparent alpha outside the coin, no backdrop, no cast shadow. NO letters, numbers, readable text, title, UI, logo or watermark anywhere, no crystals, no characters, no hands.

構圖與紅色版一致，所以尺寸和裁邊我沿用同一套流程。

Prompt

Use case: stylized-concept. Full-screen transparent overlay layer 1536x864, detailed realistic dark-fantasy, restrained. Repaint reference1 with the same composition: drifting glowing embers and tiny sparks concentrated along the left, right and bottom edges, a faint warm glow in the four corners, the CENTRAL 60% of the frame (both axes) completely transparent and clean.
