# WORLD-EXPAND-20261013｜場景與建築美術設定

用途：設定集六張設計板，非遊戲 runtime 替換。目標每張 1536×1024、不透明 WebP、≤600 KiB；總上限 3.52 MiB。主視角、可見構件正立面／剖面、局部配置示意及材料細節供後續情境圖沿用。

## 證據等級與共通限制

- **C（現行依據）**：地點身分及所屬場景，採 `src/js/story-stage-assets.js` 的 `backgrounds`、現行 `REWRITE_STAGE` 與 override。不是採用棄用接力章節推導新地點。
- **V（既有視覺）**：下列本機背景中可直接看見的輪廓、材質、家具及光源。
- **D（本輪補設計）**：圖板中所有平面、剖面、未見側面、結構接合與色碼是製作建議，不是正史建築測繪。圖上的相鄰排列也不表示地理連通；不得據此新增出口、秘密通路、解謎鎖件或劇情移動。
- 比例尺與任何 `approx.` 尺寸同屬 D，為畫面尺度參考，不具工程、地理或劇情約束力。
- 文件庫板上的 `EAST WALL` 只是 D 圖面區別名稱，未經故事資料確認方位，實際取景不得據此認定東西南北。
- 石材採炭灰至苔灰；金屬以舊黃銅及黑鐵為主，磨損露底不畫成霓虹金。一般布料墨綠、褪色灰綠，研究所保留冷窗光。陣營徽章由同工單陣營板統一，建築板布旗保持素色。
- 燈火是暖琥珀局部光，窗外是冷灰藍；同一房間的窗、燈、桌、櫃位置不得在連續鏡頭中任意左右互換。具體空間尺寸未有 C 證據，不寫死公尺。
- 遠景暮鐘維持既有輪廓；鐘體構造沿用已完成世界美術設定，不在建築板另造新版本。

## 01 暮城入口街道

設定板：`world-expand-20261013/images/scene-maku-street.webp`

**C／V 來源**：`assets/story/backgrounds/street-scenes/maku-street.webp`；現行背景鍵 `makuStreet`。入口街道、層疊石拱門及遠處塔樓構成畫面方向標記。

- 輪廓：中景石造門廊為最清楚量體；兩侧較低木石商鋪形成街谷，遠景塔樓只作尺度及城市層次。
- 鋪面：不規則石塊、有磨圓棱邊與低處積水；濕反光沿地面，不做整片鏡面大理石。路緣排水是 D 構件建議，非新可通行下水道。
- 門窗：厚木關閉百葉、黑鐵橫條，石門楣受潮較深；商鋪門與主城門材質一致但尺度不同。
- 附件：深綠遮棚、鍛鐵托架、木貨箱、桶與覆布推車；布棚下垂而非張緊現代帆布。
- 色材 D 建議：石 `#454943`、濕縫 `#202624`、布 `#253D35`、木 `#45372A`、舊黃銅 `#967348`。
- 鏡頭一致性：維持入口主軸，不把門廊換成宮殿正面；街道標誌／布旗不可自創另一陣營徽記。

## 02 尺烏據點：門外與內廳

設定板：`world-expand-20261013/images/scene-chiwu.webp`

**C／V 來源**：`assets/story/backgrounds/locations/a3-chiwu-outside.webp`、`boss-hall-interior.webp`。現行 A1 開頭使用 `bossHall`；A3-step-01／02 使用 `chiwuOutside`。本板只定義場所，首領本人的概念仍以 A1 為準。

- 外觀：狹窄濕石巷，厚重雙扇深木門，橫向黑鐵箍帶、圓環把手，門側暖燈；灰黑石柱和潮濕攀附植物。
- 內廳：高石拱與柱列；長會議桌、低背木椅、左側斗篷掛架／裝備架，後端低台與墨綠垂布。不增加王座、祭壇或地下入口。
- 桌面：卷紙、封筒、杯燈等既有工作物；圖中文字不作新增命令或故事證據。
- 構件：黑鐵鉚釘頭不整齊到機械量產感；門板直木紋、邊緣磨耗；掛架以直梁和實用掛鉤為主，不裝飾鳥雕。
- 色材 D 建議：石 `#343934`、木 `#30271E`、鐵 `#242A29`、布 `#20382E`、暖光 `#D6A65E`。
- 空間限制：門外與內廳是獨立參考，設計板不可證明兩者門位、樓層與轉角的具體關係。

## 03 曜火研究所／研究室

設定板：`world-expand-20261013/images/scene-institute.webp`

**C／V 來源**：`assets/story/backgrounds/lab.webp`，现行背景鍵 `lab`。本板定義已出現的研究室，不憑空確定整座研究所外觀。

- 量體：高尖拱花窗、周邊深木書架；中間工作桌與黄銅框玻璃球儀器是房間視覺中心。
- 窗：分格細長、石肋厚，冷光只從窗面入射；禁止改為現代落地玻璃、電腦幕牆或太空實驗室。
- 家具：書架、梯子、平厚桌面；卷紙與玻璃瓶集中工作區，保留人物站立的前景空間。
- 儀器：圓環、支腳、玻璃容器與黃銅扣環保留既有外觀，剖視僅供造型；不新增運作原理、數學公式或武器製造結構。
- 圖中沿用原背景的金色放射裝飾紋屬 V，不視為正式研究所徽章定稿；需表達陣營身分的近景布旗、徽章與門牌，採同工單陣營板。
- 色材 D 建議：木 `#3D2F25`、黄銅 `#9A7546`、石 `#45484A`、冷玻璃 `#698293`、紙 `#BBA986`。
- 狀態：整潔／事後紊亂可移動紙張小物，不可隨意移動高窗、書架主牆和工作桌。博士未完成槍另沿用武器板。

## 04 行政文件庫

設定板：`world-expand-20261013/images/scene-archive.webp`

**C／V 來源**：`assets/story/backgrounds/locations/c4-archive.webp`；C4 分別有 `archiveOuter`／`archiveHall`／`archiveInner`，本板主體是中央資料廳，不能拿局部配置替代三區劇情順序。

- 量體：高書架、金屬抽屜櫃、上層欄杆和石拱；中央閱讀桌低於櫃牆，保留深度。
- 櫃體：深綠烤漆／氧化金屬感，黄銅標籤框與拉手；抽屜寬度及重複節奏統一。標籤留模糊紙色，不新增可讀檔案名。
- 照明：綠玻璃燈罩＋黃銅支架；光落桌面而非整體綠光。燈不等於暮晶裝置。
- 小件：摺紙束、捲宗、移動文件車、壁面吊紙格架；紙張褐化但不是全部焦黑。
- 色材 D 建議：櫃 `#263B32`、石 `#3B423D`、紙 `#BDAE8D`、燈罩 `#557A44`、把手 `#9F8050`。
- 限制：不新造暗門、密碼、齒輪機關；外廊／內庫的不同牆面仍以各自現行背景為準，不自動套用此資料廳平面。

## 05 迪普霍姆礦坑與礦坑實驗室

設定板：`world-expand-20261013/images/scene-mine.webp`

**C／V 來源**：`assets/story/backgrounds/locations/bg-deepholm-mine.webp`、`bg-mine-lab.webp`。現行 C8 使用 `mine`，C9 的場景切換使用 `mine`／`mineLab`；板中雙區不是一張交通路線圖。

- 礦坑：粗木支撐、黑鐵軌道、礦車、吊鏈、工作平台及裸露岩壁。晶簇是嵌在岩面，不能像燈泡均勻排列。
- 實驗室：自然洞壁內加建木棧台、黑鐵籠與黃銅玻璃筒；主筒和上方鏈圈保留既有位置關係，暖燈與冷晶光分離。
- 岩石材質：粗裂、濕斑、尖角碎石；木支撐低亮而重磨損，金屬只有磨擦凸緣露亮面。
- 晶色：礦坑原參考較淡紫、實驗室偏青，視為既有環境與照明 V；暮晶本體、發光及熄滅規則以世界設定板為準，不藉兩地色差宣告新礦物種類。
- 色材 D 建議：岩 `#293634`、木 `#493723`、鐵 `#242D2C`、玻璃 `#73958A`、黃銅 `#947442`。
- 限制：空籠作設施設計，不新增囚犯／怪物。吊鏈、轨道及筒體是外觀而非可執行工程圖；剖面不新增出口、巨型深井或主線路徑。
