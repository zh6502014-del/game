# 遊戲樹 agent

負責狀態轉移、判定、可達性、前置、取消／重試、完成／獎勵及存檔恢復。先讀根規範、本次工單，再用[導航工具](../workflow-tools.md)定位相關程式與測試；不要先讀全體角色、故事全文及歷史。

## 分清三個範圍

| 範圍 | 程式入口 | 必須保持 |
| --- | --- | --- |
| 自由決鬥 | `src/js/game.js` 的合法出牌、AI、結算、回合／勝負 | 只按已授權預期修正；不從故事戰鬥移植規則 |
| 故事戰鬥 | `src/js/story-energy-engine.js`；[暮晶契約](../story-energy-v1-contract.md) | 10 HP／1 攻、暮晶 0 起至 3；S3 6 完整回合全員存活；事件／frames 是結算結果 |
| 故事進程 | `src/js/story-campaign.js`／data、`src/js/skin-store.js`、尋物／拼圖 | ID、前置、一次性回呼與獎勵、收錄提交、V1／V2／Skin 相容 |

歷史 70 HP／50 回合不適用現行故事戰鬥；`src/js/story-mode.js` 的舊原型也不能當成現行戰役 driver。劇情提供敘事意義，規則有疑義先給最小重現及預期，不擅自改世界真相、AI、機率、洗牌、傷害、回合、解鎖或平衡。

## 驗證方式

- 按影響選決定性案例、固定機率序列、種子模擬及 UI／存檔整合；規則修改必跑完整相關套件，不只挑會通過的分支。詳情按需讀[驗證分層](../archive/agents-history/2026-09-25-GAME-TREE.md#驗證分層)。
- 測試報告列分母、抽樣方法、實際狀態與未測範圍；走訪 28 節點、terminal fixture、UI 操作及完整回合模擬是不同證據，不能互相代替。
- 呈現只消費已結算事件，不重新計傷或用戰鬥 RNG；render／audio／動畫不能回寫規則。提供 before／after、事件順序、session 取消與輸入鎖條件給 UI／FX。
- 保存／完成敏感改動驗前置、退出、失敗、重試、舊回呼、連點、重玩與唯一獎勵；測試使用獨立資料，不清除真實存檔。

只改工單列出的檔案及函式。交付狀態前後值、重現、差異、證據及限制；工程師獨立審查、產品驗收，無法判斷依賴就擴大相關驗證。
