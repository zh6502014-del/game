# 特效／音效 agent

負責結果驅動的戰鬥動作、音畫同步、環境與生命週期。讀根規範、本次工單及相關程式；只寫指定檔案，與 UI 共用檔由產品排單一負責人，不自行改戰鬥數值／RNG／AI／回合。

## 任務入口

- 決鬥：`src/js/combat-fx.js`／`NDCombatFX`、`src/js/environment.js`，消費 `S.roundEvents`／狀態快照。
- 故事戰鬥：`src/js/story-energy-ui.js` 消費引擎事件及 frames；UI 指派者整合呈現，其他角色提供規格與驗收，避免同檔並寫。[現行契約](../archive/story-battle-ui-001.md)。
- 聲音：`src/js/game.js` 的 `AUDIO_URLS`、`AudioBank`、`playSfx`、`switchMusic`、播放池及合成備援；以[導航工具](../workflow-tools.md)定位呼叫點，不能只改其中一條播放路徑。

## 持續限制與按需條款

- 依已成立的事件順序演出；命中時顯示事件數值，不重新計算傷害或抽戰鬥 RNG。呈現隨機與規則 RNG 分離。
- 翻牌不透明、不壓扁剛體、不穿桌；涉及翻牌讀[材質條款](../archive/agents-history/2026-09-25-FX-AUDIO.md#翻牌剛體與不透明材質)。涉及攻擊讀[碰撞與浮字條款](../archive/agents-history/2026-09-25-FX-AUDIO.md#攻擊撞擊與浮字節奏)，歷史時序須核對現行引擎，不套到另一模式。
- Promise 完成或取消都要收束；退出、旋轉、重試、失焦清理 timer／動畫／DOM／audio，舊場次回呼不得污染新場次。遊戲主流程擁有回合，動畫不推進規則。
- 減少動態保留數值、狀態與結果；不等於靜音，也不更改判定。
- 涉及日夜／領域／硬幣時讀[環境條款](../archive/agents-history/2026-09-25-FX-AUDIO.md#日夜技能層與硬幣)，以雙方真實狀態決定，不用最後播放事件覆蓋場景。
- 音量、靜音、恢復預設須套用音源、播放池與備援；播放／解碼拒絕及手勢解鎖失敗不能阻塞遊戲。檢查網路成功不等於聽測；音效報告區分來源可用、播放事件與實際聽測。
- 動音訊設定或資源時讀[音訊契約](../archive/agents-history/2026-09-25-FX-AUDIO.md#音訊與本機素材契約)，保留既有 key、儲存鍵、模式與失敗備援；舊 URL／問題盤點只作查核線索。
- 新素材保留來源、授權與生成／轉檔紀錄；圖片遵守[素材預算](../art-asset-budget.md)。圖層不攔操作、不遮必要數字。

交付事件對照、取消與重入驗證、動態／減少動態證據及音訊實測限制；只跑受影響驗證，保留完整 log 路徑。凍結後交工程師，產品統一版本整合。
